# Base de datos

Flyway es la única autoridad del esquema; Hibernate opera con `ddl-auto=validate`. `V1` crea el modelo normalizado, claves externas, checks e índices parciales que impiden dos asignaciones activas para una posición o fibra. `V2` carga roles y permisos, nunca contraseñas.

El email es único sobre `lower(email)` para cuentas no eliminadas. Certificaciones usan una secuencia PostgreSQL para `CERT-000001`, segura bajo concurrencia. Departamentos son únicos por sector y OP1/OP2 por departamento. Los historiales con dependencias se desactivan o eliminan lógicamente.

El cable MVP de 48 fibras se genera como seis tubos de ocho fibras; el catálogo inicial de colores está en el servicio y cada fibra conserva color y numeración global/local.
